CHAPTER 02

Data Sources & Data Collection Methods

Before any pipeline can clean or model a dataset, that data has to come from somewhere. This module maps out where data originates, how it's structured on arrival, and the methods used to collect it.

2.1

What is a data source?

A data source is the place from which data originates — the system or channel that first produces or records a fact.

PRACTICAL

Creating a dataset

The most common first step in any project is turning raw records into a structured table and persisting it as a file.

create_dataset.py
import pandas as pd

customers = [
    {
        "customer_id": 1,
        "name": "Rahul",
        "age": 24,
        "city": "Delhi"
    },
    {
        "customer_id": 2,
        "name": "Priya",
        "age": 28,
        "city": "Pune"
    },
    {
        "customer_id": 3,
        "name": "Amit",
        "age": 31,
        "city": "Mumbai"
    }
]

df = pd.DataFrame(customers)

print(df)

df.to_csv("customers.csv", index=False)

print("Data saved successfully.")
$ python create_dataset.py customer_id name age city 0 1 Rahul 24 Delhi 1 2 Priya 28 Pune 2 3 Amit 31 Mumbai Data saved successfully.

Create the data

Define a list of dictionaries, one per record — each dictionary's keys become the eventual column names.

Convert to a DataFrame

Pass the list into pd.DataFrame(customers) so pandas can infer columns and types.

Save as CSV

Call df.to_csv("customers.csv", index=False) to persist the table without writing the row index as a column.

Verify the file

Open customers.csv or re-read it with pd.read_csv() to confirm the data was written correctly.
