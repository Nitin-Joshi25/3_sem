CHAPTER 10

Standardization

Min-max scaling squeezes values into a fixed range. Standardization takes a different approach entirely — it re-centers a distribution around zero and measures every value in units of "how many standard deviations away."

10.1

Normalization vs standardization

Students commonly confuse these two — they solve a similar problem in different ways.

Normalization

Usually scales values to a defined range.

Range: 0 to 1
Standardization

Transforms values so they're centered around a mean of zero, in units of one standard deviation.

Mean = 0  ·  Std Dev = 1

Scikit-learn's StandardScaler removes the mean and scales each feature according to its standard deviation.

10.2

Z-score formula

The z-score answers one question: how many standard deviations is this value away from the mean?

z = (x − μ) / σ
x = original value · μ = mean · σ = standard deviation
μ — the mean, at the curve's peak
x — the value being standardized
Φ(z) — cumulative probability up to x

With x = 0.3, μ = 0, σ = 1:

z = (0.3 − 0) / 1
z = 0.3

Φ(z) ≈ 61.8%

A z-score of 0.3 means this value sits 0.3 standard deviations above the mean — and roughly 61.8% of a normal distribution falls at or below it.

10.3

Manual example

The same formula, applied to an actual salary column.

manual_standardize.py
import pandas as pd

df = pd.DataFrame({
    "salary": [20000, 30000, 40000, 50000, 60000]
})

mean = df["salary"].mean()
std = df["salary"].std()

df["salary_standardized"] = (
    (df["salary"] - mean) / std
)

print(df)

10.4

Using StandardScaler

In practice, scikit-learn's StandardScaler applies the same z-score transformation across every numeric column at once.

standard_scaler.py
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.DataFrame({
    "age": [20, 25, 30, 35, 40],
    "salary": [20000, 30000, 40000, 50000, 60000]
})

scaler = StandardScaler()

df[["age", "salary"]] = scaler.fit_transform(
    df[["age", "salary"]]
)

print(df)
10.5

When to prefer standardization

Standardization is particularly common with algorithms where feature magnitude directly affects the math — many linear-model and distance or kernel-based approaches.

Usually benefits from scaling

  • Logistic Regression
  • Linear Regression
  • SVM
  • KNN
  • Neural Networks
  • PCA

Not required in the same way

  • Tree-based algorithms
  • (Decision Trees, Random Forests, Gradient Boosting)
Not a universal rule

Scaling is not automatically required for every algorithm. Tree-based models split on thresholds within a single feature at a time, so the relative magnitude between different features generally doesn't affect them the way it does linear or distance-based methods.
