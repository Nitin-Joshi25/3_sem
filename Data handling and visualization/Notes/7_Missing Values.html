Handling Missing Values

Almost no real dataset arrives complete. What you do about the gaps — and whether you understand why they exist first — shapes every result built on top of it.

Handling strategies

There is no single correct fix — each strategy trades off differently against how much data you lose and how much you assume.

Drop rows

Removes data
df_clean = df.dropna()

⚠ If 40% of a column is missing, simply deleting those rows can cause significant information loss. Use only when missing rows are a small, non-informative fraction.

Fill with mean

Numerical
df["age"] = df["age"].fillna(df["age"].mean())

A reasonable default for numerical data with no strong outliers.

Fill with median

Numerical
df["age"] = df["age"].fillna(df["age"].median())

Preferable when the data contains strong outliers, since the median is far less affected by extreme values than the mean.

Fill with mode

Categorical
df["city"] = df["city"].fillna(df["city"].mode()[0])

For categorical columns, filling with the single most frequent category.

Forward fill

Sequential
df["temperature"] = df["temperature"].ffill()

Carries the last known value forward — useful for time-series-like data.

Practical example

Combining median fill for numeric columns with mode fill for a categorical column, on one small dataset.

handle_missing.py
import pandas as pd

data = {
    "name": ["Rahul", "Priya", "Amit", "Sneha"],
    "age": [25, None, 30, None],
    "salary": [40000, 50000, None, 60000],
    "city": ["Delhi", "Pune", None, "Mumbai"]
}

df = pd.DataFrame(data)

print("Original:")
print(df)

# Numerical missing values
df["age"] = df["age"].fillna(df["age"].median())
df["salary"] = df["salary"].fillna(df["salary"].median())

# Categorical missing value
df["city"] = df["city"].fillna(df["city"].mode()[0])

print("\nAfter handling missing values:")
print(df)

INDUSTRY CONCEPT

Don't blindly fill missing data

Missing does not always mean "wrong" — and treating every gap the same way is how real data-quality issues get silently buried.

Often fine
Middle Name = missing

Plenty of people simply don't have a middle name — this could be completely valid, not an error at all.

Serious issue
Customer ID = missing

An identifier should never be absent — this is a strong signal of a broken upstream process, not something to paper over.

The core rule

Every missing value deserves a reason before it gets a fix. Filling blindly with zero can quietly turn "unknown" into "false", distorting every average, count and model trained on that column afterward.
