COMPLETE VERSION

The full pipeline, end to end

Every step above, as one script — from raw dictionary to a scaled, model-ready feature matrix.

full_pipeline.py
import pandas as pd
from sklearn.preprocessing import StandardScaler

# --------------------------------
# 1. Create raw dataset
# --------------------------------

data = {
    "customer_id": [1, 2, 3, 4, 5, 5],
    "name": ["Rahul", "Priya", "Amit", "Sneha", "Ravi", "Ravi"],
    "age": [25, 28, None, 32, 29, 29],
    "salary": [40000, 55000, 45000, None, 60000, 60000],
    "city": ["Delhi", "Pune", "Mumbai", "Pune", "delhi", "delhi"],
    "purchases": [3, 5, 2, 7, 10, 10]
}

df = pd.DataFrame(data)

print("RAW DATA")
print(df)

# --------------------------------
# 2. Remove duplicates
# --------------------------------

df = df.drop_duplicates()

# --------------------------------
# 3. Clean text
# --------------------------------

df["name"] = df["name"].str.strip().str.title()
df["city"] = df["city"].str.strip().str.title()

# --------------------------------
# 4. Handle missing values
# --------------------------------

df["age"] = df["age"].fillna(df["age"].median())
df["salary"] = df["salary"].fillna(df["salary"].median())

# --------------------------------
# 5. Feature engineering
# --------------------------------

df["annual_salary"] = df["salary"] * 12

# --------------------------------
# 6. Convert categorical values
# --------------------------------

df = pd.get_dummies(
    df,
    columns=["city"],
    dtype=int
)

# --------------------------------
# 7. Select features
# --------------------------------

features = [
    "age",
    "salary",
    "purchases",
    "annual_salary"
]

X = df[features]

# --------------------------------
# 8. Standardization
# --------------------------------

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

print("\nProcessed Features:")
print(X_scaled)
RECAP

Where every step came from

Nothing in this pipeline is new — it's every earlier module, applied in the order a real project actually needs them.

05Explore & profile the raw data first
06Drop duplicates, standardise text casing
07Fill missing values — deliberately, not blindly
08Engineer new columns, encode categories
09/10Scale numeric features before modelling
03Know which columns are IDs, not signal
The capstone idea

Preprocessing isn't a single function call — it's a sequence of small, deliberate decisions, each one addressing a specific kind of flaw, applied in an order that doesn't quietly corrupt the step before it.

Get comfortable running exactly this shape of pipeline — explore, clean, handle gaps, engineer, encode, scale — and you can adapt it to almost any tabular dataset you're handed.
