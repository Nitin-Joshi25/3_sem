Data Transformation

Cleaning fixes what's broken. Transformation reshapes what's correct into a format a model or an analyst can actually use — new columns, new groupings, new representations of the same underlying facts.

8.1

What is data transformation?

Transformation means changing data into a format that is more useful for analysis or machine learning — the values don't get corrected, they get reshaped.

8.2

Create a new column

The simplest transformation: derive a new column from an existing one with a direct calculation.

new_column.py
df["total_salary"] = df["salary"] * 12

print(df)
8.3

Create age groups

A custom function applied row-by-row turns a continuous number into a meaningful category.

age_group.py
def age_group(age):
    if age < 18:
        return "Minor"
    elif age < 30:
        return "Young Adult"
    elif age < 60:
        return "Adult"
    else:
        return "Senior"

df["age_group"] = df["age"].apply(age_group)

print(df)

8.4

Date transformation

A single date column is really three (or more) pieces of information stacked together — pandas' .dt accessor pulls them apart.

date_split.py
df["date"] = pd.to_datetime(df["date"])

df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
df["day"] = df["date"].dt.day

8.5

Categorical transformation

Machine learning models can't read the word "Delhi" — categories have to become numbers first. One-hot encoding turns a single column of labels into one binary column per category.

encode_city.py
df_encoded = pd.get_dummies(
    df,
    columns=["city"],
    dtype=int
)

8.6

Aggregation

Grouping collapses many detailed rows into one summary row per category — here, every city's individual sales figures combine into a single total.

aggregate.py
sales = pd.DataFrame({
    "city": ["Delhi", "Delhi", "Mumbai", "Mumbai"],
    "sales": [10000, 15000, 20000, 25000]
})

city_sales = sales.groupby("city")["sales"].sum()

print(city_sales)

Pattern to remember

Every transformation in this module follows the same shape: take a column (or a group of rows), apply a rule, and produce something new that's easier to reason about — a group, a bucket, a derived number, or a machine-readable flag.
