1.1

What is data?

Data is a collection of facts, observations or measurements that can be stored and processed to generate useful information.

A shopping application, for instance, collects a Customer ID, name, age, product, price, quantity, purchase date and location for every transaction. On its own this is raw data — accurate, but not yet meaningful. Only once it is aggregated does it turn into the metrics shown above: total sales, average order value, the best-selling product and the top city.

Think of a restaurant: raw ingredients are like raw data, and the cooking process — combining, transforming, seasoning — is the analysis that turns them into something useful.

1.2

Why data handling matters

Raw data rarely reaches a decision-maker in its original form. It passes through a consistent pipeline before it can be trusted or modelled.

Consider an e-commerce company predicting whether a customer will purchase a product. Two customers may look like this:

Customer A
Age24
Income45,000
Visits15
Previous purchases3
Customer B
Age45
Income2,50,000
Visits8
Previous purchases20
Income spans five digits while visits span single digits — features on very different scales. This is exactly why cleaning, transformation and normalization come before any model sees the data.
1.3

Types of data

Before data can be processed correctly, it must be classified. Every value in a dataset falls into one of four broad families.

Numerical — quantities
Categorical — labels/groups
Text — free-form language
Boolean — true / false logic

Discrete

Countable

Whole values you could count one by one — there is nothing "in between" them.

Number of students = 50
Number of products = 10
Number of orders = 25

Continuous

Measured

Measurements that can take any value within a range, including decimals.

Height = 172.5 cm
Weight = 68.7 kg
Temperature = 32.6°C

Beyond age, salary, temperature and quantity, every numerical field belongs to one of these two families — the distinction decides how you're allowed to aggregate or bucket it later.

1.4

Categorical data

Categorical data represents groups or labels rather than quantities — values like Gender = Male, City = Delhi, Payment = UPI or Product = Laptop.

Nominal

No order

Categories that sit side by side, with no ranking between them.

Delhi
Mumbai
Pune
Chennai

Ordinal

Has order

Categories that follow a natural sequence or ranking.

Low
Medium
High
1.5

Text data

Free-form language, rich in meaning but unstructured until it is processed.

Sample text data

Unstructured
"Customer is very happy"
"Product delivery was late"
"Excellent service"

Text data is the backbone of chat applications, product reviews, emails, social media posts and customer support tickets — anywhere a customer expresses something in their own words.

1.6

Boolean data

The simplest data type of all — exactly two logical values.

True / False fields

Binary

is_active = Trueis_verified = False

Booleans drive conditions, filters and flags throughout an application — "is this user active?", "has this order shipped?"

PRACTICAL

Understanding data types with pandas

The clearest way to see these types side by side is to load them into a single table and ask pandas what it sees.

data_types.py
import pandas as pd

data = {
    "name": ["Rahul", "Priya", "Amit"],
    "age": [22, 25, 24],
    "salary": [35000.0, 50000.0, 42000.0],
    "city": ["Delhi", "Pune", "Mumbai"],
    "is_active": [True, True, False]
}

df = pd.DataFrame(data)

print(df)
print("\nData Types:")
print(df.dtypes)

WALKTHROUGH

Implementation steps

Install Python

Make sure a working Python 3 interpreter is available on your machine.

Install pandas

Run pip install pandas from your terminal.

Create the script file

Create a new file named data_types.py in your project folder.

Import pandas

Add import pandas as pd at the top of the file.

Create dictionary data

Define a Python dictionary where each key becomes a column and each list becomes its values.

Convert to a DataFrame

Pass the dictionary into pd.DataFrame(data) to build a structured table.

Print the DataFrame

Call print(df) to view rows and columns exactly as pandas has structured them.

Print the data types

Call print(df.dtypes) to confirm how pandas classified each column — numeric, object or boolean.
