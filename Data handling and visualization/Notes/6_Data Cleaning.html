6.1

What is data cleaning?

Data cleaning means identifying and correcting problems in raw data before it's trusted for analysis or modelling.

6.2

Remove duplicates

Ravi's record appears twice with identical values in every column — an exact duplicate that should be collapsed to one row.

dedupe.py
df = df.drop_duplicates()

print(df)

Or, to deduplicate based on a single identifying column rather than requiring every column to match:

dedupe_subset.py
df = df.drop_duplicates(subset=["customer_id"])

The first occurrence (kept, highlighted) is retained by default; the repeat (struck through) is dropped.

6.3

Clean text

Our dataset contains "Delhi" and "delhi" — two labels that should represent exactly one city. Stripping whitespace and standardising case fixes this in one line.

df["city"] = df["city"].str.strip().str.title()

6.4

Convert data types

Columns that should be numeric sometimes arrive as text, or contain values that simply aren't numbers.

convert_types.py
df["age"] = pd.to_numeric(df["age"], errors="coerce")
"twenty-five"
→
NaN
while a valid value passes straight through
"32"
→
32.0

errors="coerce" converts any value that can't be parsed as a number into a missing value, instead of crashing the whole conversion.

6.5

Validate data

Being the right type isn't enough — a value can still be logically impossible. Age, for example, can never be negative.

validate.py
invalid_age = df[df["age"] < 0]

print(invalid_age)

Once flagged, invalid records can be filtered out entirely:

filter_valid.py
df = df[df["age"] >= 0]
6.6

Full cleaning example

Put together, every fix from this module runs as one short pipeline over the original imperfect dataset.

full_cleaning.py
import pandas as pd

data = {
    "customer_id": [1, 2, 3, 4, 5, 5],
    "name": [" Rahul ", "Priya", "Amit", "Sneha", "Ravi", "Ravi"],
    "age": [25, 28, None, 32, 29, 29],
    "salary": [40000, 55000, 45000, None, 60000, 60000],
    "city": ["Delhi", "Delhi", "Mumbai", "Pune", "delhi", "delhi"]
}

df = pd.DataFrame(data)

# Remove duplicate records
df = df.drop_duplicates()

# Clean names
df["name"] = df["name"].str.strip().str.title()

# Clean city values
df["city"] = df["city"].str.strip().str.title()

# Convert numerical fields
df["age"] = pd.to_numeric(df["age"], errors="coerce")
df["salary"] = pd.to_numeric(df["salary"], errors="coerce")

print(df)

The duplicate is gone, names and cities are consistently capitalised, and both numeric columns are proper floats. The remaining NaN values are genuine gaps — that's the subject of the next module.

What changed

6 rows → 5 rows (duplicate removed). "delhi" and " Rahul " → "Delhi" and "Rahul" (text standardised). age and salary → proper numeric dtypes, ready for real arithmetic instead of accidental string concatenation.
